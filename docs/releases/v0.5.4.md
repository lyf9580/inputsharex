## 输入流转X v0.5.4

Windows 客户端 **v0.5.4** · Android 配套应用 **v0.3.5**。

### 本次更新

- 绝对坐标鼠标：跨屏首包直接定位，电脑与安卓之间按共享边的实际比例衔接，移除原先等待指针反馈的纠偏流程。
- 修复安卓返回电脑后又跳回进入位置的问题。
- 安卓鼠标速率可调，默认 **3.75 倍**；光标大小可调，默认 **1.5 倍**。调节即时生效并保存。
- 白色光标配细灰色描边和轻微阴影；系统合成光标可在系统设置等隐藏普通悬浮窗的页面显示。
- 左键拖动使用完整手指触摸序列，修复抖音评论区无法按住滑动的问题。
- 抖音前台时将竖向滚轮转换为短距离手指滑动，支持视频上下切换和评论区滚动。手动按下优先接管，断开时清理触摸状态。
- 保留 Wi-Fi 加密直连、无线 ADB、有线连接三种方式，继续使用无视频控制通道和 UHID 键盘。
- 修复共享结束时软键盘设置恢复的竞争条件。
- CI 从源码编译控制转发组件、执行 Python 与 Java 回归检查，并发布校验和。

### 下载与安装

- Windows：下载 **InputShareX.exe**，退出旧客户端后替换运行。
- Android：下载 **inputsharex-android-0.3.5.apk**。
- **Android 发布签名已更换为私有密钥。** 旧发布版本或本地 debug APK 无法直接覆盖安装此 APK，需要先卸载旧安卓 App，再安装新版。卸载会清除安卓 App 的本地设置，安装后请重新授予所需权限。电脑端设备配置不受影响。
- 使用本次新签名安装后，后续正式版继续沿用此签名。

### 校验

附带 **SHA256SUMS.txt**，包含 EXE 与 APK 的 SHA-256 校验值。

Android 发布证书 SHA-256：

`AC:3E:25:4A:BC:34:AC:0B:F9:03:D4:EF:59:39:83:1F:17:D5:D6:82:A1:E9:B4:0E:F9:0F:DE:45:C9:34:12:BB`

### 验证

已在小米平板 Android 16 实测加密直连、跨屏位置、系统设置页光标、抖音视频滚轮切换与评论区拖动；本地 Python 回归检查 140 项通过，另有 Java 指针解析与触摸手势检查。
